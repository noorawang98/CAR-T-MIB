# Manuscript/code alignment requiring author resolution

Scientific definitions were not changed merely to make source agree with prose.

1. **Functional labels.** `mem_exh_final.py` computes both k-means and quadrant labels. Latest region/neighbourhood scripts read `GRPR_quad_M5`. Calling those final analyses exclusively “k-means grouping” would not match the supplied code. No corresponding final functional-group bootstrap implementation was identified in this selected workflow; ROC confidence-interval bootstraps are a different procedure.
2. **Tumour regions.** The second archive now supplies `region_annot.py`: low-30% tumour-program reference, chromosome-ordered 101-gene moving average, mean absolute deviation, reference 95th-percentile threshold, CNV-positive OR tumour-program P90, and two rounds of six-neighbour majority voting. The default program remains `mel`; the other implemented program is `lym`. A malignant epithelial program is not implemented. The moving average is applied to the concatenated chromosome-ordered gene vector; it is not reset at chromosome boundaries. The reference inferCNV scripts remain a distinct single-cell analysis.
3. **Clinical GSEA.** The author confirmed the final model is `~ group + tp`, with categorical Pre/Post. The final release path is now `pervimib_de_only → pseudobulk_adjtime_gsea`, reading `_adjTime.csv` and ranking by limma-estimated log2 fold changes for PR versus SD/PD. Continuous infusion-relative days and log2FC ranking do not match this implementation. `pervimib_enrich` remains an explicitly unadjusted branch. The sorting/name-pairing bug found in pseudobulk_adjtime_gsea was corrected in the release; see GSEA_UPDATE.md before interpreting existing results.
4. **Spatial definitions/families.** The final clinical `perivascular_permutation_test` uses >=3 vessel-high neighbours out of six, 1,000 permutations, two-sided section-level P values and retained directional sensitivity results. Latest mouse simultaneous-neighbourhood analysis uses 2,000 permutations; the pooled mouse kNN entry uses 1,000. Preserve panel-specific counts. The newly supplied mouse `region_annot` uses >=2 endothelial-high neighbours for `region_niche = Perivascular`; its output is read by the latest region consumers. Restored `niche_v2` uses separate 100/200-µm ring definitions for the existing `neighbour_rings` feature analysis. These are not identical to the unified >=3/6 clinical definition. `perivascular_enrichment` requires at least three GR **and** three PR spots in a region to include it in the enrichment denominator.
5. **Fourier null.** `fourier_m5_mib` uses 300 toroidal shifts per section and pools the resulting null correlations across sections. The plus-one denominator is therefore total pooled null size + 1, not necessarily 301. Permutation labels/graphs alone should not be described as preserving label-field spatial autocorrelation.

These are release/source-alignment notes, not new analyses or demands for additional experiments.
