# Method order and execution branches

Folder numbers express the manuscript's methodological sequence, not a single dependency-free batch run. Keep mouse, clinical and pan-cancer data branches separate.

| Order | Folder | Key calculations / sequence |
|---|---|---|
| 01 | `01_reference_annotation` | `cnv_infercnv` inferCNV → `cnv_verdict` CNV verdict → `st_annotate` clinical reference/deconvolution annotation. Existing reference and deconvolution outputs are inputs. |
| 01b | `01_spatial_cnv_regions` | `raw_car_counts` raw CAR/total UMI → `build_spot_master` spot master → existing folder-02 `car_cutoff` CAR calling → `region_annot` spatial CNV/tumour zones. Supplies `spot_regions.csv`; marker/region-definition differences are documented. |
| 02 | `02_scissor` | CAR calling (`car_cutoff`); pooled ComBat/Scissor (`scissor_pooled`) and alpha evaluation (`alpha_opt`, `alpha_auc_full`); sparse-label assembly (`sparse_labels`); forward/reverse ROC (`scissor_pooled_auc`, `reverse_auc`). Restored `scissor_coefs` exports legacy cohort coefficients and curated `prepare_scissor_spot_table` exports the integrated spot table. `scissor_meta_preprocess.R` is an author-session metadata helper, requiring `dataset` and `GEOID`. |
| 03 | `03_functional_states` | `dump_msigdb` gene-set export → `gsva_grpr_v2.py` expression/panel preparation → `gsva` GSVA scores; `ml_predict_grpr` feature expression/classifier → `dump_c7` C7 export → `clinical_gsva` LASSO/state panels → `clinical_gsva_run` GSVA → `mem_exh_final` within-section z scores and labels. `auc_in_mib`, `auc_cross`, `auc_per_slide` retain distinct ROC targets/scopes. Do not substitute their labels for one another. `legacy_dependencies/gsva_grpr → kmeans_grpr → marker_scores → final_labels` reconstructs the separate def5 input read by `common.grpr_labels()`; these are not current M5-quadrant labels. |
| 04 | `04_fourier` | `fourier_m5_mib` band reconstruction, toroidal-shift correlations and BH correction. Functional labels and annotated spot fields must already exist. |
| 05 | `05_mib_definitions` | `mib_mouse_aligned` mouse-aligned clinical MIB; `pervimib_deconv` deconvolution-defined perivascular MIB; `ring_mib_v1` mouse ring features; restored `niche_v2` supplies the separate ring-niche input for `neighbour_rings`; `mib_definition_agreement` definition agreement. `run_cibersort_stnr.R` requires the external CIBERSORT implementation/signature. `cibersort_pancancer` retains clinical pseudobulk component scoring/ranking only and runs after folder 09 prepares that input. |
| 06 | `06_spatial_neighbourhood` | Mouse `neighbour_rings` mixed-model feature families; added `car_proportions` CAR-positive proportion tables; `region_define_stats` → `grpr_by_region_stats` regional GR/PR tables → `grpr_tam_caf_coloc` separate TAM/CAF neighbourhoods → `grpr_tam_caf_simultaneous` simultaneous neighbourhoods → `perivascular_enrichment` section-specific fold enrichment. `nr1_panel_knn_analysis` is the separate pooled-section/stratified-permutation neighbour analysis. Clinical `ccr1_coloc` prepares `ccr1_spots_all.csv` → `perivascular_permutation_test` final per-section 1,000-permutation analysis. `myeloid_caf_colocalization_statistics` retains correlation/OR statistics and CSV output only; despite its original filename, it no longer draws figures. |
| 07 | `07_functional_correlations_gsea` | `prep_data` and `score_correlation_suite` functional/marker correlations; `blocks` supplies marker definitions. `nr1r1_rank` → `tcell_gsea.R` functional GSEA. Gene-set selection/result tables remain because they document the analysis; rendering is excluded. |
| 08 | `08_imaging_conversion` | `batch_mics_to_h5ad.py` converts imaging tables. Imaging proximity/statistical analysis entry points were not present in the archive. |
| 09 | `09_clinical_pseudobulk_gsea` | `pervimib_pseudobulk` perivascular MIB pseudobulk → `pervimib_de_only` limma-voom DE → **`pseudobulk_adjtime_gsea` final Pre/Post-adjusted GSEA**. `pervimib_enrich` is the separate unadjusted enrichment branch, not the final adjusted GSEA. `mibdestvi_pseudobulk` separately prepares deconvolution-defined MIB pseudobulk for folder 05 component scoring. |
| 10 | `10_survival` | `export_survival_exposure` patient-level exposure export → `survival` clinical Cox/log-rank tables. `survival_km_cox.R` and `survival_tests_generic.R` are separate cohort/table entry points. `pancancer_survival.R` retains pan-cancer age/gender-adjusted Cox and cutoff calculations; later stage/race fallback plotting versions are excluded. |

Original script headers and input/output paths document the expected filenames. `PROJECT_ROOT` refers to the original analysis-data tree, not this repository. Use the configured runner to make modules in other release folders importable.
